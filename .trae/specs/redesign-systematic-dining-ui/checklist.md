# Checklist

## 设计系统
- [x] 两端使用暖米白、深炭灰、品牌橙和语义状态色组成的统一视觉体系
- [x] 颜色、排版、间距、圆角、边框、阴影和动效由集中变量管理
- [x] 页面不再依赖玻璃态、发光、大面积渐变和装饰性大阴影建立层级
- [x] 核心功能不使用 Emoji 图标，图标或文字语义清晰一致

## 管理后台
- [x] 登录页品牌明确，表单、错误和提交状态层级清晰
- [x] 侧边栏、顶部区域和内容容器形成稳定且高效的工作区
- [x] 看板按日期、关键指标、待处理信息和最近订单组织内容
- [x] 分类、菜品和订单页面具有一致的标题、筛选、主操作、数据和分页层级
- [x] 菜品管理使用适合批量扫描和操作的表格化布局
- [x] 窄屏时导航可用，表格在自身区域滚动，页面无整体横向溢出

## 用户端
- [x] 点餐页分类定位、菜品信息、价格、库存与加购操作清晰易触达
- [x] 购物车支持调整数量、删除、清空，并实时展示小计与合计
- [x] 确认订单页的信息核对、用餐方式、金额和提交操作层级清晰
- [x] 订单列表与详情清晰展示状态、商品、金额、时间和可用操作
- [x] 底部操作栏适配设备安全区且不遮挡内容
- [x] 主要触控目标不小于约 44px，并有明确按下和禁用反馈

## 状态与可访问性
- [x] 加载、空数据、错误、提交中、成功、禁用和不可用商品状态完整
- [x] 状态信息不只依赖颜色表达，并具有可理解的文字或图标语义
- [x] 键盘焦点清晰可见，主要交互具备可识别名称和状态
- [x] 启用减少动态效果偏好时，非必要动画被关闭或显著缩短

## 回归验证
- [x] `admin-web` 执行生产构建通过
- [x] `uniapp` 执行 H5 生产构建通过
- [x] 后台登录、看板及分类/菜品/订单管理关键流程可用
- [x] 用户端点餐、购物车、确认订单、订单列表和详情关键流程可用
- [x] 常见桌面、窄屏后台和手机视口无页面级横向溢出或固定栏遮挡
- [x] 未修改接口、路由、权限、数据模型和核心业务流程
