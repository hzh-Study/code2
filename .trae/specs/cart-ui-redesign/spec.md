# 购物车页面 UI/UX 重设计

## Why
当前购物车页面功能完整，但视觉层次单薄、品牌感弱、空状态缺乏引导、交互反馈不够细腻。需要在保持所有现有业务逻辑（增删改购物车、结算跳转、登录校验）不变的前提下，全面提升视觉品质与交互体验。

## What Changes
- **空状态**：用品牌插画替代纯 emoji，增加「去逛逛」引导按钮
- **购物车卡片**：增加左侧彩色数量指示条、图片圆角加大、价格突出显示、删除手势提示
- **步进器**：改为胶囊式 +/- 按钮，增加数量变化动画
- **底部结算栏**：增加商品件数提示、结算按钮增加渐变与微动效
- **整体色调**：强化品牌橙色作为强调色，背景增加微妙渐变纹理
- **过渡动画**：列表项增删时增加滑入/滑出过渡

## Impact
- Affected code: `uniapp/src/pages/cart/cart.vue`
- 不修改 API 调用、路由跳转、业务逻辑、数据结构

## Requirements

### Requirement: 空状态引导
- **WHEN** 购物车为空
- **THEN** 显示品牌风格插画、文案「购物车空空如也」、副文案「去逛逛美味吧～」、可点击「去点餐」按钮

### Requirement: 商品卡片视觉升级
- **WHEN** 购物车有商品
- **THEN** 每项商品卡片左侧有品牌色数量指示条，图片圆角 12px，菜名加粗，价格用品牌色突出，数量步进器改为胶囊式

### Requirement: 结算栏增强
- **WHEN** 购物车有商品
- **THEN** 底部栏显示「N 件商品」提示，结算按钮有品牌橙渐变背景与按下缩放反馈

### Requirement: 交互反馈
- **WHEN** 用户点击 +/- 或滑动删除
- **THEN** 有明确的视觉反馈（缩放、颜色变化、数量动画）

## Acceptance Criteria
- 空状态有品牌风格引导
- 商品卡片视觉层次清晰
- 步进器触控区域 >= 44px
- 底部结算栏信息完整
- 所有交互有明确反馈
- `npm run build:h5` 构建通过
- 功能路径完整：加购、改数量、删商品、结算跳转
